# Лисьи оценки

Сайт для оценок кино и планирования просмотра. Хостинг — GitHub Pages, каталог — TMDB, облако — Firebase.

## Что где лежит
- `src/style.css`, `src/app.js` — стили и код (правим их).
- `src/data/*.json` — стартовые данные (`tmdb.json` без картинок, только ссылки).
- `src/index.src.html` — каркас страницы с метками `{{файл}}`.
- `posters/` — постеры встроенных записей (подгружаются лениво).
- `index.html` — **собранный** файл, его отдаёт GitHub Pages. Руками не правится.
- `build.py` — сборка. `tests/smoke.py` — проверки. `.github/workflows/ci.yml` — запуск проверок на каждый коммит.

## Работа
1. Правьте файлы в `src/`.
2. `python3 build.py` — пересобрать `index.html`.
3. `python3 tests/smoke.py` — проверить (нужен `pip install playwright` и `playwright install chromium`).
4. Закоммитьте `src/`, `posters/` и `index.html` вместе. CI упадёт, если `index.html` не соответствует `src/`.

Выкладывать нужно `index.html` **вместе с папкой `posters/`**, а также прежние `sw.js`, `manifest` и иконки.

## Версия базы
В `app.js` есть список `MIGRATIONS`. Чтобы изменить формат данных, добавьте функцию в конец списка — номер версии посчитается сам, старые копии (из браузера, облака, импорта) приведутся к новому виду при открытии.

## Журнал ошибок
Сбои сохранения и запросов пишутся в журнал на вкладке «Данные»; на вкладке появляется красный значок «!», если что-то не сохранилось.
